# Chapters I–V — Integrated Resource Progression

Core assumption: Create + addons, Mekanism, Applied Energistics 2, KubeJS/T&K resources, Iron's Spells 'n Spellbooks, Ars Nouveau, and a very small number of custom machines.

## Progression law: discover once, automate forever

T&K3 should distinguish **discovery** from **production**.

A progression resource may require exploration the first time — meteorite, magical structure, boss, special biome — but the player should not be forced to repeat that hunt forever. Once the relevant chapter is mastered, either the same chapter or the next chapter should unlock a renewable/automatable production route.

Target resource lifecycle:

**Discover → manually process → assisted processing → automate → scale**

Normal bulk resources should never remain exploration-only after they become factory ingredients.

---

## Chapter I — A New Beginning

### Resource layer
Vanilla iron, copper, coal, redstone, quartz, lapis/amethyst; Create zinc and Andesite Alloy.

### T&K resource
**Kinetic Assembly** (using the old Rotation Mechanism art). It is used only in important workshop/core components, not as a token that converts into every Create machine.

### Technology
- hand tools and furnace
- first Create rotation
- water/wind power
- crushing, milling, pressing
- first weapon-component manufacturing

### Magic
Archwood, amethyst, Arcane Essence or other magical finds may appear as teasers, but Chapter I does not demand repeated magical exploration.

### Automation target
By chapter end / early Chapter II:
- logs/planks
- cobble/stone
- basic crop production
- basic ore processing
- Andesite Alloy
- simple mechanical components

### Exit
A real workshop exists and the player has learned that T&K equipment and machines are manufactured from components.

---

## Chapter II — Forged in Motion

### Resource layer
Brass, steel, glass/rubber/sealing materials and processed metal forms: plates, rods, billets, blades, guards and machine frames.

### T&K resources
- **Sealed Component** (old Sealed Mechanism art)
- **Tempered/Reinforced Steel Plate** if a dedicated plate is useful; old Sturdy Invar Sheet art can be repurposed later if preferred

### Technology
- heated Create processing
- fluid handling
- sequenced assembly
- forging/tempering equipment chains
- first serious weapon and armor manufacturing
- early trains/logistics components may be introduced, not completed

### Steel rule
Steel becomes a T&K industrial metal before Mekanism becomes dominant. Early production can be Create/blast-based. Later Mekanism makes steel faster and easier rather than being the only way to make it.

### Automation target
All Chapter I bulk materials become unattended:
- iron/copper/zinc processing
- brass
- Andesite Alloy
- basic components
- first steel route

### Exit
The workshop has become a small factory and the player's normal equipment can be produced through repeatable production lines.

---

## Chapter III — Beyond the Walls / Precision Discovery

This is the first major **discovery → domestication** chapter.

### Discovery resources

#### Applied Energistics 2
- Certus Quartz
- Charged Certus
- Sky Stone
- processor presses / meteorite knowledge

The first meteorite is exploration. Certus itself must quickly become renewable through budding growth.

#### Ars Nouveau
- Archwood
- Source Gem
- Source generation
- first Imbuement Chamber / Source Jar

#### Iron's Spells
- initial Arcane Essence
- first blank runestone / magical focus materials
- first meaningful spellbook/scroll progression

### T&K resources
- **Siliceous Compound** — Create-produced silicon precursor for AE2
- **Polished Amethyst**
- **Amethyst Tube**
- **Runic Shard** — initially discovered/earned, not yet mass-produced
- existing incomplete Logic / Calculation / Engineering Processor assets enter the AE2 production chain

### AE2 progression
Chapter III should end with **basic ME storage**, not full autocrafting:
- charger/growth
- processor production
- cables
- terminal
- drive
- 1k/4k-class storage

Processor production is Create-assisted so AE2 already feels like part of the factory.

### Magic automation
Ars Source is renewable through sourcelinks. A Create crop/tree farm can intentionally feed an Agronomic Sourcelink, making magic generation part of the player's infrastructure.

### Automation target
- Certus Quartz growth
- automatic Charged Certus
- Fluix production
- silicon / Siliceous Compound
- Source generation
- all Chapter II metals/components

Initial Arcane Essence and Runic Shards may still require exploration in modest quantities.

### Exit
The player has digital storage and renewable magical energy, but must still explore to learn/acquire the first pieces of advanced magic.

## Chapter IV — Arcane Foundations & Electrification

### Technology transition
Create is no longer the only energy language.

- Create Crafts & Additions (or equivalent bridge) turns rotation into the first FE network.
- Mekanism basic machinery opens.
- Osmium and tin become meaningful industrial resources.
- First Metallurgic Infuser / selected powered processors appear.
- AE2 processor production becomes highly automated.

### T&K resources
- **Mana Infused Compound**
- **Mana Infused Sheet**
- **Rune of Infusion**
- **Runic Shard** now gains a renewable route
- optional electrically treated casing using old Zinc Machine art

### Custom machine: Runic Catalyst
Repurpose the existing Runic Catalyst asset into a real Chapter IV machine.

Its job is cross-system processing, not generic smelting. Candidate inputs:
- FE
- Ars Source
- Iron's Arcane Essence / ink fluids
- amethyst / Source Gems
- metal or AE2 components

Candidate outputs:
- Mana Infused Compound
- Mana Infused Sheet treatment
- Rune of Infusion
- renewable Arcane Essence route
- specialty spell/equipment components

### Arcane Essence rule
Exploration should unlock Arcane Essence, but not supply thousands forever.

After the player proves magical progression, the Runic Catalyst can condense renewable inputs such as Source + amethyst/XP/catalyst material into Arcane Essence at a real energy/resource cost.

### Iron's ink
Lower ink tiers should become automatable during IV–V. Higher rarity ink can remain gated by difficult materials/bosses. The point is to automate routine spell production without making legendary magic free.

### Mekanism role
Do not use Mekanism simply as “a faster Crusher.” In this chapter it introduces:
- infusion
- electrical processing
- material treatment
- first compact powered machines

Create remains superior at visible bulk physical manufacturing.

### Exit
Mechanical industry, FE, AE2 and both magic systems have an explicit connection.

---

## Chapter V — Age of Industry

Chapter V is where the player stops being a craftsman feeding every machine manually and becomes an industrial operator.

### Mekanism progression
- Enrichment / Infusion fully integrated
- advanced control circuits
- Basic/selected Advanced factories
- oxygen/chemical processing
- 2x ore processing standard
- 3x processing unlocked for normal bulk ores where balance allows
- speed upgrades remain limited/gated

Rare/boss/arcane materials are not automatically eligible for maximum ore multiplication.

### AE2 progression
- Controller-scale network
- Pattern Providers / Molecular Assemblers
- full processor automation
- autocrafting
- factory import/export/storage integration
- larger cell tiers

AE2 now becomes the control/logistics layer over both Create and Mekanism.

### T&K resources
- **Radiant Sheet**
- **Radiant Induction Core**
- **Resonating Quartz**
- **Technical Tube**
- **Reinforced Alloy Plate** (repurposed Sturdy Invar Sheet art)

### Resonating Quartz
Working concept:

AE2 crystal technology + Ars Source + Iron's arcane component → Resonating Quartz.

It becomes a material for:
- advanced AE2 components
- Runic/Resonance machinery
- high-tier weapon cores
- precision sensors
- advanced industrial components

### Radiant Induction Core
A high-energy component that bridges:
- electrical power
- precision manufacturing
- advanced machine construction

It is not another universal “mechanism token”; it appears only where an induction/high-energy core makes sense.

### Technical Tube
Used where the recipe genuinely needs a protected high-tech conduit:
- Mekanism chemical machines
- advanced custom machines
- arcane-fluid/energy interfaces
- later endgame infrastructure

### Optional custom machine: Resonance Chamber
Use/recolour the old Enderium Machine/Casing art.

The Resonance Chamber is a Chapter V cross-system machine requiring FE and optional Source/chemical inputs. It handles the few recipes that should feel more advanced than a Create basin but are not natural Mekanism recipes.

### Automation target at end of Chapter V

**Fully scalable**
- iron, copper, zinc, brass, steel
- osmium and tin
- basic Create components
- AE2 Certus / Charged Certus / Fluix / silicon
- Logic / Calculation / Engineering processors
- Ars Source
- routine Arcane Essence
- common/uncommon magic production materials
- Runic Shards
- Mana Infused Compound/Sheet

**Automatable but expensive**
- Resonating Quartz
- Radiant components
- higher storage components
- advanced Mekanism alloys

**Still discovery/boss gated**
- unique boss cores
- highest-rarity magical catalysts
- chapter keystones
- legendary weapon imprints

The important distinction: a boss/structure may provide the **knowledge or seed item**, but the player should not need to loot the same tower 60 times to operate a factory.

---

## End-of-Chapter-V factory vision

A healthy Chapter V base should look like:

**Create farms / bulk lines**  
→ feed **Ars Source generation** and physical components  
→ feed **Mekanism powered/chemical processing**  
→ feed **Runic/Resonance custom processing**  
→ all routed and scheduled by **AE2**  
→ producing equipment, kingdom supplies and progression materials.

No core system becomes obsolete; each has a distinct production language.
