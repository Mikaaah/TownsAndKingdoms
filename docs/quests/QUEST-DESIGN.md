Rules:
- 25–40 meaningful main quests/chapter
- not one quest per ingredient
- critical path must be visually obvious
- use quests for milestones, discoveries and tutorials
- encyclopedic mod detail goes optional
- hard gates explain why
- rewards cannot break the next chapter
