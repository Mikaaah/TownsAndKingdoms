# Test Plan

## Environments
clean client / dedicated server / fresh survival / reload world / multiplayer / worldgen seed sweep

## Smoke
launch, world load, server join, recipe viewer, quests, skill tree, Create machine, combat

## Progression
For each chapter start from the previous chapter's realistic inventory, obtain every mandatory item without Creative, complete every gate, verify no later-stage skip, test death/relog/restart.

## Recipe regression
removed recipe has replacement, no required output is unobtainable, canonical materials consistent, no unintended easy duplicate remains.

## Boss
solo, multiplayer, arena reset, death/re-entry, restart mid-fight, reward duplication, cheese/breakouts.

## Performance
record client/server RAM, startup, worldgen stutter, entity-heavy fights, factories, MineColonies + factories.
