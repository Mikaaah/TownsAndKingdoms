# T&K3 Roadmap

## Pillars
1. Low bloat, high integration
2. One unified progression
3. Create is manufacturing, not the entire story
4. RPG combat and character builds are first-class
5. Magic changes what can be made; engineering scales it
6. Exploration and bosses provide discoveries/materials
7. MineColonies represents civilization growth without mandatory grind
8. The player always knows what matters
9. The ending is a world-scale project, not simply reaching one dimension

## Main chapters
1. A New Beginning
2. Forged in Motion
3. Beyond the Walls
4. Arcane Foundations
5. Age of Industry
6. Kingdoms Rise
7. Shattered Realms
8. Convergence
9. The Eternal Kingdom

## Development phases
### Phase 0 — Foundation
mod selection, clean boot, performance baseline, scripting/quest/resource framework, testing process

### Phase 1 — Vertical slice
Chapters I–II end-to-end: survival, skills, Epic Fight, first Create workshop, manufactured equipment, first settlement hooks, quests, tests

### Phase 2 — World opens
Chapters III–IV: exploration, dungeons, bosses, magic, cross-system materials

### Phase 3 — Scale
Chapters V–VI: advanced Create, logistics, metallurgy, MineColonies, food economy

### Phase 4 — Endgame
Chapters VII–IX: dangerous realms, bespoke bosses, convergence recipes, final project/event

### Phase 5 — Polish
balance, progression regression, readability, performance, resource consistency, release testing
