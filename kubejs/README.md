# KubeJS
T&K3 integration layer.

- `server_scripts/recipes/` chapter/system recipes
- `server_scripts/systems/` reusable integration helpers
- `server_scripts/removals/` deliberate removals/redirects
- `startup_scripts/` registration-time content
- `client_scripts/` client presentation
- `data/tnk/` datapack functions/tags/loot/worldgen
- `assets/tnk/` models/textures/lang/resources

Do not port T&K2 wholesale. Rebuild against verified 1.21.1 registries and the new progression.
