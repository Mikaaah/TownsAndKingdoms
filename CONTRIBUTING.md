# Contributing to Towns & Kingdoms

Thanks for helping improve Towns & Kingdoms! This repository hosts modpack development material and the [player wiki](https://mikaaah.github.io/TownsAndKingdoms/).

## Report a bug

Use the repository's existing issue templates. For gameplay issues, include:

- Minecraft and NeoForge versions, modpack build/version, and any changed or added mods.
- What you expected and what happened, with steps to reproduce.
- Relevant screenshots, logs or crash reports (remove access tokens, server addresses and personal information).
- The affected chapter, quest, recipe, world-generation feature or skill-tree node, if applicable.

## Suggest improvements

Open a feature request before substantial gameplay changes. Explain the player experience, how it affects progression, and potential compatibility or performance costs. For recipe and quest changes, mention alternative routes and whether the result remains automatable.

## Documentation and pull requests

- Keep submissions focused and explain what changed and why.
- Update the wiki or related guide whenever you change progression, recipes or controls.
- Check relative links and Markdown formatting before submitting.
- Don't upload third-party mod JARs, proprietary assets or material without redistribution permission.
- For code or data changes, include the environment and tests you used; note anything untested.

Use a pull request for contributions rather than committing directly to the main branch. Thank you!
