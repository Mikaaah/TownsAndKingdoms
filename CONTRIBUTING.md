# Contributing

## Branches
- `main`: preserved stable T&K2 / eventual stable T&K3
- `tnk3-development`: T&K3 integration branch
- use short-lived feature branches for risky implementation work

## Before progression changes
1. identify chapter/system
2. check material registry and dependency ledger
3. classify change: KEEP / REPLACE / REMOVE / REDIRECT / LATE-GATE
4. test from a survival-equivalent state
5. update quests/docs when a gate changes

Keep commits scoped to one coherent system or feature.
