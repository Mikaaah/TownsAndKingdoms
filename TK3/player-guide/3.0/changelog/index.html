Towns & Kingdoms 3.0 — Changelog

Living changelog for the rebuild of Towns & Kingdoms.

Target: Minecraft 1.21.1 / NeoForge

This page focuses on player/development-relevant changes between the T&K2 era and T&K3. The detailed working ledger is maintained in: TK3/docs/CHANGELOG_3.0.md

Legacy reference

  • T&K2 Mod List
  • T&K2 — A New World | The 1.20.1 Update

3.0 — Rebuilt foundation

Platform

  • Moving to Minecraft 1.21.1.
  • Moving to NeoForge.
  • T&K3 is a rebuild; T&K2 scripts/configs/assets are reference material instead of the runtime base.

Progression

  • FTB Quests becomes the visible campaign/progression layer.
  • AStages enforces actual gameplay locks.
  • End Remastered is integrated into End access.
  • Boss kills and milestones can unlock reusable processing permissions/catalysts.

Character progression

  • A large Passive Skill Tree becomes the character progression foundation.
  • Six main classes, eighteen subclasses and four professions form the current design.

Combat

  • Epic Fight is the core combat framework.
  • Weapons of Miracles and Simply Swords are part of the selected weapon stack.
  • T&K3 maintains compatibility/movesets for its own selected stack.

Magic

  • Iron's Spells focuses on combat spellcasting.
  • Ars Nouveau focuses on arcane crafting, processing and automation.
  • Just Another Witchery Remake joins the selected magic layer.
  • Cross-mod recipes/progression intentionally connect the magic systems.

Technology

  • Create is the early/mid-game mechanical backbone.
  • Mekanism becomes a later technology layer.
  • AE2 becomes the late-game storage/logistics/autocrafting system.
  • Create Aeronautics is integrated as a progression-based travel/engineering system.
  • Compact automation is preferred over unnecessary multi-step processing bloat.

Loot & gear

  • Apotheosis / Apothic systems provide the affix, gem and socket framework.
  • Default balance/progression is being customized for the pack.

Bosses, mobs & exploration

Selected 3.0 content currently includes Cataclysm, Alex's Mobs, Alex's Caves, Ice and Fire: Community Edition, Bosses' Rise, Mowzie's Mobs, Twilight Forest and Amplified Nether.

Towns & multiplayer

  • MineColonies is selected as the primary settlement/kingdom system for T&K3. MCA Reborn was only an early T&K3 consideration and was not part of T&K2.
  • MineColonies: Epicfied (Epic Colonies) is now the primary MineColonies ↔ Epic Fight test candidate.
  • Epic Fight X Minecolonies Compat remains the simpler fallback if Epic Colonies fails version or stability testing.
  • The two Epic Fight bridge mods are never installed together.
  • Create: MineColonies Link connects colony supply requests to Create logistics.
  • Initial server limits target 100 citizens per colony, a 12-chunk colony radius, disabled colony force-loading, default pathfinding limits and a 40-raider cap.
  • FTB Chunks + FTB Teams remain the current claims/team foundation.
  • Additional integrations are evaluated for cross-mod value and server impact rather than mod count.

Integration

  • KubeJS, ProbeJS and LootJS form the scripting/integration base.
  • Dedicated KubeJS integrations are locked for Create, Mekanism, Ars Nouveau, Iron's Spells and AE2.
  • The pack is being designed around intentional cross-mod compatibility rather than isolated mod progression.

Dungeons & structures

The temporary definitive dungeon baseline is Integrated Dungeons & Structures, Integrated Dungeons Arise, Integrated Cataclysm, Integrated Stronghold, YUNG's Better Dungeons and Dungeons & Taverns. Large/Create-heavy structures will be made rarer where needed.

Optimization & QoL

The conservative optimization baseline now includes Sodium, Lithium, ModernFix, FerriteCore, ImmediatelyFast, Entity Culling, BadOptimizations, Dynamic FPS, AllTheLeaks, Clumps, FastSuite, spark and Chunky.

The selected QoL baseline includes JEI, Jade, Jade Addons, AppleSkin, Mouse Tweaks, Controlling, Shulker Box Tooltip, Lootr, Iris and BetterF3. Explorer's Compass is intentionally excluded.

Still in development

  • final world generation
  • economy
  • expanded Towns & Kingdoms systems
  • final version pins
  • final Epic Fight compatibility coverage

FreeTerraForged is now the primary Overworld terrain candidate, replacing ReTerraForged. The current Overworld test stack combines FreeTerraForged with Alex's Caves, Biomes O' Plenty, Oh The Biomes We've Gone, Upgrade Aquatic, Atmospheric, Autumnity, Environmental and [Let's Do] BloomingNature.

The End test stack now uses BetterEnd: New Dawn as the primary overhaul, with Nullscape under terrain-layer testing. YUNG's Better End Island and End's Phantasm have been rejected to avoid unnecessary overlap.

The Nether test stack now uses Amplified Nether + BetterNether: New Dawn + YUNG's Better Nether Fortresses. Gardens of the Dead has been rejected.
