Project reference

Artwork & credits

Credits and source releases for the official artwork, item textures and Create model viewer.

The Towns & Kingdoms logo, banner and colours use the official artwork supplied for T&K3.

Item art & Create models

The recipe workshop uses original item textures and Minecraft JSON models extracted from 1.21.1 releases. 1416 item icons are available. T&K3 component icons and frame models follow the current KubeJS startup scripts.

Create models and textures are credited to simibubi and the Create team. Minecraft assets belong to Mojang / Microsoft. Mod artwork belongs to its respective creators.
