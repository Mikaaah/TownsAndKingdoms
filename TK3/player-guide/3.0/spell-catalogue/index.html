Coverage and versions

Public base/addon source snapshots plus the author’s Cataclysm 1.21.1 reference release, not a scan of installed jars. Geomancy Plus and Alex’s Caves: Spellbooks are documented separately; their complete version-specific registries were not available. Numeric defaults can be overridden. This is an upstream reference catalogue, not a promise that every source definition is enabled in Alpha 1.0. The alpha mod list identifies projects but no jar versions. For exact availability, cost, cooldown, level and damage, inspect the installed spell tooltip and JEI.
