Classes & professions

Six classes, eighteen subclasses, seven professions, all paths and exact scripted bonuses.

6 CLASSES · 18 SUBCLASSES · 7 PROFESSIONS · 1387 NODES

Shape your character through shared constellations, a class foundation and three subclass paths. This guide is generated from the supplied v3.2.3 SIX PATHS script. Browse every node or jump to a class below.

How to choose your path

Start at Adventurer’s Origin, travel through the shared tree and unlock a class root. Finish the class foundation to reach the mastery hub and Specialisation Gate. Choose your subclass, then invest along its three independent paths. Advanced class lobes are optional.

Every node costs one point from the same point pool. You may choose one class and one subclass. Profession masteries are limited to three; each profession allows three of its six focus nodes. Taking profession nodes is separate from choosing a class.

The script recommends an initial maximum of 260 points and describes an intended endgame spend of 150–220. These are design recommendations, not a verified server point cap.

Reading stats and prerequisites

Bonuses below reproduce the script’s display text, including penalties. Percentage attributes, percentage-point chances and flat armour/reach values are different operations; do not add them all as flat percentages. Display values are rounded by the script. A node called Fury or Guard grants its listed statistics; its name alone does not add an Epic Fight move or an Ars spell.

The documentation extractor assumes the Minecraft, Iron’s Spellbooks and Apothic attributes exist. The script has fallbacks when optional attributes are missing. In-game tooltips and server configuration determine the actual loaded result.

Build planning

Choose your intended role first, then compare the subclass entry penalties. Invest enough in the class foundation to unlock specialisation before spreading into optional lobes. A single subclass path is cheaper than the three-path Ascendancy route; plan your profession focuses around activities you actually use.

For a front-line build, compare Warrior’s Juggernaut with Cleric’s Crusader. For spellcasting, compare Mage’s mana and school paths with Cleric and Occultist. Battlemage is a Mage subclass; Juggernaut belongs to Warrior. These are planning suggestions, not a damage ranking.
