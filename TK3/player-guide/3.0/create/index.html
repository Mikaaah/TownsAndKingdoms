Quick start

STRIPPED LOG + ANDESITE ALLOY → ANDESITE CASING → MANUAL KINETIC MACHINE → STONECUTTER → POWERED WORKSHOP.

Craft the first casing by hand, or automate it using the Deployer route. Press ingots into sheets once your first Press is running. The first machine frame needs seven Andesite Alloy, one wooden slab and one Andesite Casing.

Main machines

The Press, Mixer, Deployer, pumps and smart machines still come from their tier frame. Use the full Create workshop filter to see both the existing machine recipes and these support recipes.

What stays native

Mine zinc ore for your first zinc supply; use the listed furnace recipes. Capture a blaze with an Empty Blaze Burner before heated brass production. Worldgen stones and decorative palettes keep their natural sources and native building recipes.

Reconfiguration & recycling

Metal blocks and ingots unpack at the matching 9:1 ratio. Clear recipes explicitly reset filters, schedules and other configured tools; they discard the old configuration. Reconfiguration recipes switch supported chassis, meters and gearboxes without creating extra material.
