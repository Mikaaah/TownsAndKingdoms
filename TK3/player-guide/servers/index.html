Field guide/Play together

Play together

Towns & Kingdoms has an official EU and US server direction, with community events and shared projects. Use the pack's current server list and Discord for availability, beta windows, event announcements and joining details.

Build a shared settlement

Give projects a visible home: a farm supplying the kitchen, a public processor line, a warehouse, roads and shops. A Quest Projector can display goals, while a Trading Hub directory helps players find useful destinations.

FTB Teams and Chunks support group organization and land claims. Progression's team settings govern supported unlock sharing; they do not make every personal choice shared. Origins, equipped titles and skill spending remain character choices.

Match the installation

The inspected TNK3 platform is Minecraft 1.21.1, NeoForge and Java 21. The base export pins NeoForge 21.1.262. Later custom builds must be distributed with their matching dependencies.

Keep the same approved custom-mod JARs, KubeJS startup/server/client scripts, required root JSON files, quest files and resources on the relevant sides. A full restart is needed after item registration, protocol or startup changes. Recipe-only edits can be reloaded once the matching installation is in place.

Do not install a TNK2 download expecting it to launch TNK3. The shared CurseForge project's latest public client is still TK2 3.05 for Forge 1.20.1.

Pregeneration and travel

A Minecraft world border's configured size is its diameter. RTP limits are distances from the configured centre. Compare both with the actual pregenerated area before enabling travel.

The supplied FTB Essentials config uses a 25,000 maximum RTP distance, a 500 minimum and 600-second cooldown, with the End excluded. These are source-config values, not a live verification of either official server.

Changing generation presets or Excavator definitions does not rewrite already generated chunks and vein data. Plan those updates before generating a new official world.

Report a problem

Include the pack snapshot/build, whether it happened in singleplayer or multiplayer, the steps involved and the relevant log/crash report. Use GitHub issues or the community's designated support channel.
