Field guide/The current skill tree

The current skill tree

Spend points on the effects you use. The current Pufferfish configuration contains 588 nodes, each costing one point, with a total spending limit of 175. The category has no exclusive-root setting and does not erase skills on death.

Six configured paths

The imported tree retains six internal path families, each containing 98 nodes. Their IDs are compatibility references, not six mandatory character classes.

The live node descriptions have been modernized beyond some historical internal names. Follow the connections and read the effect, rather than assuming an ID implies an old class or profession rule.

What nodes can change

The configuration includes direct attribute bonuses and scripted passives. Examples include potion duration, resource handling, mining/building utility, recovery and optional magic attributes.

Iron's Spells and Ars bonuses apply through their installed integrations. A description mentioning an optional mod does not make that mod a new hard dependency. Scripted passives can have conditions or caps; their complete node description is shown in the reference.

Plan with the current data

Browse every configured node to search by title, internal ID, path or effect. It is a read-only reference to the supplied configuration. It does not spend points or alter your character.

The old web class planner and its six-class/eighteen-subclass restrictions are retired from the current wiki. Skill connections, point availability and server configuration govern the in-game tree.

Keep your systems distinct

Skill points develop your tree. Activity XP develops your character. An origin adds its own two perks. Titles provide a separate display/passive selection. Owning a title does not automatically apply every title's bonuses at once.
