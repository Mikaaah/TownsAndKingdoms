# T&K3 Skill Tree — Artwork & Icon Direction

Current art direction for the finished T&K3 class/subclass skill-tree artwork.

## Non-negotiable style

- true retro RPG pixel art
- coarse pixel density matching the approved Warrior, Ranger, Rogue, Cleric and Occultist examples
- large visible pixel blocks
- stepped edges
- chunky 16/32-bit-style shading
- limited palette per icon
- bold dark outlines
- simple readable lighting/shading
- transparent background
- compact roughly circular bust/portrait composition
- readable at small skill-node scale

Avoid:
- painted/anime illustration rendering
- fine smooth linework
- anti-aliased illustration strokes
- painterly gradients
- detailed individual hair strands
- micro-detail
- high-resolution art that only imitates pixel art

## Character consistency rules

- subclasses must visibly derive from their parent class character/family
- silhouette and palette must remain distinct enough to read at small size
- do not change established character identity merely to add detail
- keep the older approved Mage version rather than replacing it with the later regenerated Mage set
- use the approved original Occultist character design as the basis for the Occultist family
