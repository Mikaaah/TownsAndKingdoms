# Assembly tools · Chapters I–X

All finishing tools are held in a Deployer. Ordinary tools wear; named milestone rewards use the same item with the native Unbreakable component.

[Complete tool and reward table](PLAYER_PATHS_EN.md#finishing-tools--rewards) · [Exact mechanism recipes](https://mikaaah.github.io/TownsAndKingdoms/workshop/?family=campaign)

Boss core deployments use `keepHeldItem()` explicitly. The final Keystone retains all four cores. Only the tier I frame has a manual raw-material startup recipe.
