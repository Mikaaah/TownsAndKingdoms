# Documentation and project references

The current [field guide](https://mikaaah.github.io/TownsAndKingdoms/) follows the TNK3 Beta 1.0 pack. The [version reference](https://mikaaah.github.io/TownsAndKingdoms/status/) identifies its files and the [mod inventory](https://mikaaah.github.io/TownsAndKingdoms/mods/) lists its contents.

Use the issue tracker for reproducible pack problems and the community for questions, feedback and builds. Historical recipe and terrain documents describe earlier development snapshots; use the current guide for playing the beta.
