## ◆ Reach each new workshop

- **Chapter 1:** handcraft separate starting Kinetic Machines. Build the Press from raw iron before you need sheets. The Kinetic Mechanism keeps its slab → Alloy → Alloy → Hammer sequence.
- **Chapter 4:** heated steel and Precision Machines bootstrap the first Infuser, power, Charger and Inscriber. Produce the Basic Control Circuit before sequencing the Inductive Mechanism. AE2 processors use the original meteorite presses.
- **Chapter 6:** build the first gas equipment with Ender Machines. Produce HDPE before assembling the Chemical Machine.
- **Chapter 9:** build the first SPS and Nucleosynthesizer from Containment equipment before producing the new Singularity Frame.

## ✦ Artwork and installation

All supplied item and quest artwork is explicitly modeled. The custom texture folder is included in the block/item atlas, and frame parent models use separate paths. Install the assets on **every client**, then fully restart Minecraft. [Install this update →](INSTALL_FIXES_EN.md)

Decorative AE2 stone uses its own stone again. Decorative conversions cannot create a progression frame. The **Inductive Machine has one approved recipe: Steel Casing → deploy Inductive Mechanism**; no two-slab recipe is registered for that frame by this package.
