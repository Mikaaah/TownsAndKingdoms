# T&K3 · ITEMS & ASSETS

The supplied ZIP provides the custom mechanism, unfinished mechanism, material and casing textures. **99 quest and information icons** are registered as items without crafting recipes. All animations retain their original `.png.mcmeta` files.

The custom `tk3_supplied` texture directory is explicitly included in Minecraft’s block/item atlas. Item models use the supplied art; machine builders reference separate frame parent models to avoid model cycles. Custom frames use native Create casings at chapters 1–3 and supplied casing faces in later workshops.

Install the assets on every client as well as the server. **Fully restart Minecraft** after updating startup scripts; `/reload` alone does not register models or custom items. See [installation instructions](INSTALL_FIXES_EN.md).
