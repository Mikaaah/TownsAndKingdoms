# The ten chapters

Create forms the manufacturing backbone. Each chapter adds a useful production capability, then connects it to the next. Adventure and magic supply discoveries and materials without a blanket lock on dimensions or the Wither.

**Chapter numbers run I–X. Internal production tiers run 0–9.** Manual and automated Andesite both construct the same Andesite Machine.

| Chapter | Main component | What opens up |
|---|---|---|
| [01 · Manual](chapter-01/) | Makeshift Mechanism | Clay, Andesite Alloy and the first manually crafted machine body. |
| [02 · Andesite](chapter-02/) | Rotation Mechanism | Affordable repeated machinery and the first automated material loop. |
| [03 · Copper](chapter-03/) | Sealed Mechanism | Tree sap, rubber, fluids and improved logistics. |
| [04 · Brass](chapter-04/) | Precision Mechanism | Heated alloys, precise assembly, controls and Crushing Wheels. |
| [05 · Calculation](chapter-05/) | Calculation Mechanism | Create-built processors and practical ME logistics. |
| [06 · Reinforced](chapter-06/) | Reinforced Mechanism | Steel, electrum, wires and the first electrical engineering projects. |
| [07 · Industrial](chapter-07/) | Industrial Mechanism | IE heavy processing and the 4× ore chain. |
| [08 · Arcane](chapter-08/) | Arcane Mechanism | Source, Mana and magical materials join the production line. |
| [09 · Eclipse](chapter-09/) | Eclipse Mechanism | Chromatic materials, ink recovery and the 5× ore finish. |
| [10 · Creation](chapter-10/) | Creation Core | The final shared project for your entire factory. |


## Mechanisms, bodies and working machines

A mechanism is a production component. A machine body is a crafting ingredient used to construct equipment. Placing a decorative body does not turn it into the corresponding processor.

The early bodies are **Andesite**, **Copper** and **Brass**. **Calculation Machine** leads to AE2 construction. Native **Light Engineering** and **Heavy Engineering Blocks** remain the bodies consumed by their current IE construction recipes; Workshop-style Light/Heavy machine models also exist, but should not be substituted for the native blocks in a recipe.

The **Creation Core** is the final assembly project. The scripts also craft a Creation Machine from eight cores and a Netherite Block; its functional uses are still unassigned.

## Build for repeatable output

Use dedicated lines for Alloy, Rotation, Sealed and Precision Mechanisms before moving on to processors. A late assembly still consumes the earlier mechanisms. Keep buffers of common sheets, tubes, rubber, Redstone and silicon.

Most main mechanism sequences use **one loop and a guaranteed output**. The Creation Core deliberately runs **two passes through nine Deployers**. Read each chapter for fluid amounts and tool wear.

## Exploration stays part of the world

Factory ingredients and local mod mechanics still matter. The Twilight Forest retains its own progression; End Remastered retains its native eye requirements. These are separate from a global pack chapter lock.

No new boss-to-eye table is configured in the current custom loot script. The [adventure guide](../exploration/) explains what is confirmed.
