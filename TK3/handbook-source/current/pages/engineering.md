# Immersive engineering

Create handles repeatable routine manufacturing. Immersive Engineering contributes heavy processing, electrical infrastructure and mineral extraction. This keeps both systems useful without maintaining parallel factories for the same basic task.

## Where the work moved

| Former IE function | Current direction |
|---|---|
| Metal Press | Create Deployers, Presses and rolling operations |
| Sawmill | Create wood processing |
| Bottling Machine | Spout filling |
| Assembler / Automated Workbench | Crafting and Mechanical Crafters |
| Mixer / Alloy Kiln | Create mixing and alloy processing |
| Fermenter / Squeezer / Refinery | Converted recipes and Create Diesel Generators routes |
| Conveyors and routine pipes/pumps | Create item/fluid logistics |

The replacement system preserves supported native recipes through conversions. It does not make every recipe of every addon interchangeable; use JEI to see the installed result.

**Coke Oven, Blast Furnace, Crusher, Arc Furnace, Excavator/Bucket Wheel, wires and distinctive electrical machinery remain relevant.** Immersive Petroleum is outside the selected setup; Create Diesel Generators is the fuel-production direction.

## Reinforced and Industrial construction

Reinforced Mechanisms introduce Light Engineering. Industrial Mechanisms introduce Heavy Engineering and IE Crusher processing. Their native engineering-block recipes consume four Steel Plates, two Treated Wood Planks, two matching mechanisms and one basic Electronic Component.

Electrum and Copper wire use rolling. Aluminium wire uses one Aluminium Ingot for two wires. Use the appropriate mould or reusable tool only when the installed recipe actually requests it.

## Survey before you excavate

The Excavator extracts IE mineral deposits; it does not create mineable ore blocks. Survey the location and arrange power, output sorting and spoil storage before building the complete multiblock.

The integration adds ten resource deposit definitions and ten rare discoveries when their optional materials are available. Original IE pools gain compatible resources and reduced ordinary recipe failure rates.

| Deposit | Primary pool |
|---|---|
| Ferruginous / Copper / Auriferous / Zinc-bearing strata | 60% matching Create stone, 40% matching ore |
| Certus Quartz Pocket | 60% Certus, 20% Sky Stone, 18% Quartz, 2% Fluix |
| Volcanic Strata | Scoria and Scorchia |
| Magnetic Fault | Neodymium and magnetic cave materials |
| Primordial Fossil Bed | Amber, Bone, cave Limestone and Pewen Sap |
| Ambrosial Strata | Ambrosium, Zanite and Holystone |
| Living Root Seam | Liveroot, Iron Ore, Root Strand and Torchberries |

Pools have biome restrictions. Aether and Twilight deposits use their own biome tags; they are not generic Overworld veins. Recipe percentages apply before IE's separate distance/failure behavior.

New deposit definitions do not reroll existing generated vein data. Server pregeneration and retrogen remain separate choices.
