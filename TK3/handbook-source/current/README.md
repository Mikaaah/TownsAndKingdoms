# TNK3 Beta 1.0 field guide

This documentation follows **Towns & Kingdoms 3 — Beyond the Forge · Beta 1.0**, for Minecraft 1.21.1, NeoForge and Java 21.

[Open the guide](https://mikaaah.github.io/TownsAndKingdoms/) · [Mod inventory](https://mikaaah.github.io/TownsAndKingdoms/mods/) · [Version reference](https://mikaaah.github.io/TownsAndKingdoms/status/) · [Community](https://discord.gg/CRYk3uDPVt)

The reference includes the current production route, character systems, custom features and full mod selection. Recipe definitions and quest records describe the beta’s contents; they are not a claim that every campaign page is finished. Original TK2 documentation remains in its archive.
